# 0024: Consumables that raise stats permanently

- **Date:** 2026-10-17
- **Status:** Accepted (books as the form: proposed)
- **Decision:** Rare consumables permanently raise one stat, like Realm of
  the Mad God's potions. Idea: forbidden books, such as treatises on color
  theory. Fits the book's Colour Revolt, after which color was banned.
  One book per stat; exact names and amounts TBD.
