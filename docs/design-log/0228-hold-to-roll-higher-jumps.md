# 0228: Holding a roll key rolls any shape; jumps go higher

- **Date:** 2026-10-25
- **Status:** Accepted
- **Decision:** Holding left or right is enough to tumble along for every
  shape, triangles and squares included (the roll push is now strong enough
  to tip a flat face over its corner from rest). A plain jump rises about
  112 px, twice a full-size shape's height (was ~11 px). Nose dive now leaps
  1.5x jump speed (~250 px, about twice a jump) so it stays special.
- **Why:** the user's call: flat-sided shapes needed jump spammed to move.
