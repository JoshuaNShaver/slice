# 0176: New families start at a 40° apex

- **Date:** 2026-10-20
- **Status:** Accepted
- **Decision:** A new family's triangle (isosceles or irregular) starts
  with a 40° apex, not 45°. The +5° per heir is unchanged, so the climb is
  40°, 45°, 50°, 55°, then equilateral on the 4th heir (one more marriage
  than before). Families already past 40° keep their angle. Changes log
  0031's starting angle.
- **Why:** sharper soldiers, as in the book, and more of the early lives
  spent soldiering before a triangle is regular enough for other work.
