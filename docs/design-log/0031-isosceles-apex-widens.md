# 0031: Isosceles apex widens toward equilateral

- **Date:** 2026-10-17
- **Status:** Accepted (start angle changed by 0176)
- **Decision:** A new family's (non-irregular) triangle is isosceles with a
  45° apex. Each heir's apex is 5° wider: 50°, 55°, then 60° (equilateral)
  on the 3rd heir. From equilateral the normal +1 side rule applies.
- **Why:** the book's rule (the apex widens about 0.5° a generation), sped
  up to fit permadeath. A narrow apex hits harder (180° − corner), so
  climbing trades the sharpest corner for status.
- **Answers** open question 2. How right triangles fit is still open (Q1).
