# 0225: Players still pass through each other; ledges are solid

- **Date:** 2026-10-25
- **Status:** Accepted
- **Decision:** In the solid world (log 0221) players still pass through
  each other (and soldiers), so crowds can't block a hub or a doorway.
  The Center's ledges stop being one-way: they're solid, and you get onto
  one from beside it.
- **Why:** the user's call; a one-way ledge is something you pass through.
