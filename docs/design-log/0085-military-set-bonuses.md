# 0085: Military sets get modest bonuses

- **Date:** 2026-10-18
- **Status:** Accepted (leather); Proposed (bronze, iron, steel)
- **Decision:** A military set is its four slots (points, plating, eye,
  voice); pigment doesn't count. Leather +10 force. *Proposed:* bronze +10
  vigor, iron +10 rigidity, steel +10 torque. Secret until completed, like
  every set (log 0045).
- **Why:** modest next to the cave's +15 sets; each tier a different stat,
  so it's a sidegrade, not only a ladder.
  Answers DESIGN §9's question on military set bonuses.
