# 0213: Admin command to set a player's sides

- **Date:** 2026-10-22
- **Status:** Accepted
- **Decision:** `players set sides <n> [--id who]` (3 to 64) changes the current heir's shape in place, keeping level, stats and gear, and saves it to the family. Irregulars stay irregular; a triangle made a polygon becomes regular, a polygon made a triangle equilateral; the apex is cleaned for the new shape.
- **Why:** testing shape-gated places, quests and looks without marrying up.
