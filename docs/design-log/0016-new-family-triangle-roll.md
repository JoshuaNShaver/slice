# 0016: New families roll their starting triangle

- **Date:** 2026-10-17
- **Status:** Accepted (missing 10% open)
- **Decision:** A new family's first character is a triangle, rolled:
  equilateral 0%, right 40%, acute 40%, irregular 10%.
- **Open:** these add up to 90%. Until the last 10% is assigned, the code
  rescales the weights (right and acute about 44.4% each, irregular about 11.1%).
