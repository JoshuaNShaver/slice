# 0204: Chits for work, coins for trade

- **Date:** 2026-10-21
- **Status:** Accepted (coin colour Proposed)
- **Decision:** Pay is **chits**, spent at the barracks. Missions pay
  chits, and so does work: a tradesman at the dock buys logs for 200
  chits each, so working speeds up the barracks' unlocks. The trade
  money is plain **coins**, drawn in a colour unlike any in the game
  (*proposed:* verdigris, a deep blue-green). Neither shows on the HUD:
  both go in a Purse tab in the Tab panel. Supersedes 0203.
- **Why:** work should feed the war (log 0177); coins belong to merchants.
