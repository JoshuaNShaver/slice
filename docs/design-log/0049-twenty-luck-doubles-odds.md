# 0049: 20 luck doubles odds; irregulars are born with it

- **Date:** 2026-10-18
- **Status:** Accepted
- **Decision:** Luck multiplies good-outcome chances by 1 + luck/20, so
  **20 luck doubles them** (was 50, log 0023). Irregulars are born with
  **+20 luck** on top of the 0–10 roll, so they start at double odds or
  better (a 20% base crit). Luck from gear (Eye up to +15, the gilded set
  +15) stacks on top. Chances still cap at 100%.
- **Why:** makes luck from gear feel worth having.
