# 0189: The game's menus look like the main menu

- **Date:** 2026-10-21
- **Status:** Accepted
- **Decision:** Every in-game panel (Esc menu, controls, character sheet,
  chests, orders, shop, countdown) uses the main menu's theme: torn
  parchment panels and pencilled buttons, fields, dropdowns, item slots and
  tooltips (`SketchBox`), lettered in IM Fell English. Speech bubbles and
  the quest tracker are pencilled too. IM Fell is also the game's default
  font, so signs, names and damage numbers match. The admin terminal keeps
  its monospace.
- **Why:** the user asked for one look across the game, from the menu.
