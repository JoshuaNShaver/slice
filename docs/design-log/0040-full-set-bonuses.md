# 0040: Full-set bonuses

- **Date:** 2026-10-17
- **Status:** Accepted
- **Decision:** Wearing all five gear slots in the same tier completes that
  tier's set, which adds a bonus of its own. A mixed set gives nothing.
  - Rose: +15 force.
  - Mint: +15 torque (speed).
  - Lilac: +15 rigidity (defense).
  - Gilded: +15 vigor (+150 health) and +15 luck.
  A full set shows as a halo in its color around your shape.
- **Why:** makes each tier's set special and worth chasing.
- **Note:** drops roll a random slot, so a full set takes about 11 drops of
  that tier, roughly 75 room kills at the 15% drop chance.
