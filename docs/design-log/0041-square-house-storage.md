# 0041: Squares get a house with storage chests

- **Date:** 2026-10-18
- **Status:** Accepted
- **Decision:** Once a family reaches a square, it gets a **house** with
  **chests** for storage. Gear stored there carries over to later heirs,
  so only square-or-better runs benefit from past runs' gear. Triangle
  runs always start with nothing.
- **Why:** gives the climb out of the triangle ranks a concrete reward,
  and keeps the early game a pure roguelite.
