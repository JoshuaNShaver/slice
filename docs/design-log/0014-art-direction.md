# 0014: Chalk pastels on parallax parchment

- **Date:** 2026-10-17
- **Status:** Accepted
- **Decision:** Fixed pastel chalk palette with 2–3 crosshatch styles as a
  learnable identity code. Parchment background with ink-stain layers moving
  at different parallax speeds.
- **Note (proposed):** dark sepia ink outlines so pastels read on parchment.
