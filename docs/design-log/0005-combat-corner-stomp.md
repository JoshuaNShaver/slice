# 0005: Combat is corner stomping

- **Date:** 2026-10-17
- **Status:** Accepted (multi-hit: tentative)
- **Decision:** Jump and land on enemies, Mario style. Only corners deal
  damage. Damage per corner = 180° − corner angle (360/n for regular shapes).
  More sides means multiple corner hits while rolling over an enemy.
- **Why:** Sharper shapes hit harder. A full roll always totals 360 damage,
  so shapes trade burst for hit count without per-class tuning.
