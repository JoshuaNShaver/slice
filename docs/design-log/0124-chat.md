# 0124: Chat for everyone

- **Date:** 2026-10-18
- **Status:** Accepted
- **Decision:** Every player can chat. Enter (rebindable) opens a typing
  line; Enter sends, Esc closes. A line goes to everyone in the same part of
  the world (overworld, underworld, or one squad's mission), shown in the
  chat log and as a speech bubble over the speaker. Name shown: the
  username online, else the family name. The server cleans lines (one
  line, 160 characters) and allows 5 lines per 5 s. The log sits bottom
  left with keys, and new lines fade after 10 s; open, it shows the whole
  log and scrolls. On a touch screen a Chat button joins the top row, and
  the chat moves to the top left with the typing line on top (the phone's
  keyboard covers the bottom half), big Send and close buttons, and the
  game's touch controls paused while it's open.
- **Why:** players asked for it RuneScape style; it's also where admin
  commands are typed (0125). Overworld/underworld/mission rooms rather
  than each place, so a small player count still hears each other
  (Proposed; change `PlayerChat.room_of`).
- **Open:** moderation (mute, report, word filter); whispers; chat
  history across joins.
