# 0081: Countdown popup with Ready

- **Date:** 2026-10-18
- **Status:** Proposed (the user asked for the popup and Ready; the rules below are Claude's)
- **Decision:** While a squad musters (10 s) or waits to go home after a
  victory (6 s), each player in it sees the timer in a popup, top right,
  with a **Ready** button. A muster leaves as soon as everyone in it is
  ready. After a victory, Ready sends just you back to the barracks at once.
- **Why:** skip the wait when no one else is coming.
