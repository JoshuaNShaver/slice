# 0076: Priests' rolling puzzles explore other dimensions

- **Date:** 2026-10-18
- **Status:** Accepted (direction; not built)
- **Decision:** Circles (10+ sides) gain rolling puzzles that pair mobility,
  death traps and enemies (armor helps with all three) with using other
  dimensions to get around or through obstacles. Ideas: a Lineland view
  (only a single vertical line on screen, navigate a maze by it alone), and
  slice-view swapping, where 3-D objects pass through the plane, to learn
  3-D traversal. These give more gear and prestige.
