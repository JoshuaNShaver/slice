# 0048: Irregulars get +50 luck (double odds)

- **Date:** 2026-10-18
- **Status:** Superseded by 0049
- **Decision:** Irregulars are born with **+50 luck** on top of the normal
  0–10 roll, so every good-outcome chance is at least doubled: drops,
  certificates, crits (a 20% base crit). Replaces 0023's "2x luck", which
  was built as twice the roll (0–20). Old irregular saves are converted.
