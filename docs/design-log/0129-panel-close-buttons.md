# 0129: Every panel has a close button

- **Date:** 2026-10-19
- **Status:** Accepted
- **Decision:** Every HUD panel (character sheet, menu, controls, chests,
  the General's orders, the Quartermaster's shop) has an ✕ in its top
  right corner. Pressing the use key (E) again closes the chests, orders or
  shop instead of using the nearest thing. Tab and Esc already toggle
  their own panels.
- **Why:** players expect an ✕, and on touch there was no Esc to press.
