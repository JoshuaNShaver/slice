# 0065: Equilateral is not a starting choice

- **Date:** 2026-10-18
- **Status:** Accepted
- **Decision:** A new family picks **isosceles (45° apex)** or **irregular**.
  Equilateral is removed from the start selection; it's reached by
  climbing the isosceles apex (log 0031). Isosceles stays the default.
- **Why:** starting equilateral would skip the climb and give a square heir
  right away.
