# 0018: Main menu with server selection and 3 family slots

- **Date:** 2026-10-17
- **Status:** Accepted
- **Decision:** The main menu picks a server (offline, host, or join by
  address) and one of 3 family save slots. A slot can create a new family,
  play it, or delete it.
- **Note (proposed):** saves live locally in `user://families/` for now. A
  public server would need to hold families itself to prevent cheating.
