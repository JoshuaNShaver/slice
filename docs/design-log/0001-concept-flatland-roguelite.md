# 0001: Concept is a Flatland roguelite

- **Date:** 2026-10-17
- **Status:** Accepted
- **Decision:** The game is an exploration roguelite set in *Flatland*, with
  procedurally generated mazes and dungeons.
- **Why:** Replaces the earlier "walk a high-dimensional surface to a known
  minimum" puzzle concept. The Flatland setting gives progression (side
  count = rank) and a world to explore.
