# 0206: Barracks prices in thousands of chits

- **Date:** 2026-10-21
- **Status:** Accepted
- **Decision:** Abilities: nose dive 1,000, rush 2,500, spike up 5,000
  chits. Military gear, a full set of four pieces: bronze 400, iron 800,
  steel 2,000 (100, 200, 500 each). Leather, from the drill yard, is the
  main set before a player starts working.
- **Why:** a full bag of logs (2,000 chits) buys a steel set, so work
  is the fast road through the barracks.
